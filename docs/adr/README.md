# Architecture Decision Records

ADRs registram uma escolha específica, alternativas, rationale, consequências e condições de reconsideração.

Um ADR não pode contradizer a constituição sem um processo explícito de mudança constitucional.

## Estados

```text
PROPOSED
ACCEPTED
REJECTED
SUPERSEDED
WITHDRAWN
```
