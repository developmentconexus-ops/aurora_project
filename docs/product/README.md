# Aurora Product Documentation

O Product Blueprint define o que Aurora é e quais invariantes devem sobreviver à troca de modelos, frameworks, protocolos, runtimes, dispositivos e provedores.

## Horizonte duplo aprovado

```text
Visão de longo prazo
→ constitucional, completa e evolutiva

Próximo escopo executável
→ detalhado, pesquisado, testável e contratual
```

A visão não será reduzida a um MVP. A implementação não fingirá conhecer antecipadamente toda a arquitetura futura.
